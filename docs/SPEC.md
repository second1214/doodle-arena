## 1. ゲーム概要
1. スマホで2Dの絵を手描き → 突起から手足を自動検知 → 保存。
2. 能力値・必殺技・性格を設定。
3. 他人のキャラ（無ければ CPU キャラ）と斜め上視点の3Dアリーナで1対1バトル。勝敗でランキング変動。
4. 観戦モードで保存キャラ同士の AI 対戦を観る。

## 2. キャラメイク
### 2.1 ペイント
- キャンバス 512×512、ペン太さ数段階、消しゴム、取り消し、色パレット。
- 保存の正はストローク列（座標を量子化・差分符号化、数KB〜30KB）。

### 2.2 突起自動検知（検知専用シルエット）
- **塗りつぶしは検知のためだけに使う。3Dで動くキャラは元の線画（塗っていない絵）。**
- 手順: 256²に縮小して描画 → 線の隙間を閉じる（膨張→収縮）→ 外側から塗りつぶし、その残りをシルエットとする → 距離変換 → 胴体半径の約0.45倍で「削って戻す」処理（opening）をした残りを胴体コアとする → シルエットから胴体コアを引いた差分の塊のうち、細長いもの（長さ/幅>1.5）を手足とする。
- 関節（回転軸）= 塊と胴体の接点の中点、先端 = 関節から最も遠い点。
- 手足判定: 関節→先端が下向き±50°以内、かつ関節が重心より下 → 足。それ以外 → 手。
- 本数制限なし。離れたストロークは近ければ結合、遠ければ胴体の装飾扱い。
- 検知不能時は手0本・足0本 → 体当たり攻撃・滑走移動。
- 切り出し: 検知で得たパーツ領域を元の線画に当てて、線画をパーツごとに切り出す。
- パラメータ（α・面積下限・縦横比）はデータとして外出しし、`algoVersion` で管理。
- 結果は保存時に凍結（アルゴリズム改良で既存キャラは変わらない）。

### 2.3 3D表現
- Three.js。キャラは紙人形の板（Y軸だけ回るビルボード、カメラ側へ約15°後傾、原点は足元）。
- 左右の向き変更は横反転を0.15秒補間（ペーパーマリオ式）。
- 切り抜き描画（半透明合成なし）、パーツの重なり順は固定値で制御。
- 影は足元の丸影のみ（高さの手掛かりとして必須）。
- 性能目標: スマホ60fps、発熱時30fps。描画呼び出し50以下、弾は上限128（エンジン保護）。

### 2.4 属性（保留）
- 色→属性→効果はデータ定義（JSON）。読み込み時に再計算。
- 初期案: 赤=火(炎上) 青=水(鈍化) 黄=光(ビーム) 緑=草(設置罠) 黒=闇(カウンター)。

### 2.5 能力値
- 攻撃力 / 防御力 / 移動速度 / 体力 / スタミナ（回避力は廃止）。
- 総ポイント固定・各項目の上下限あり（数値は試作で決める）。
- スタミナ = 最大量と回復速度。攻撃・ダッシュ等で消費（詳細は §10）。

### 2.6 性格（AI の行動傾向）
- 作者が選ぶ。例: 猛攻 / 慎重 / 狙撃 / トリッキー。
- AI は行動ごとの点数（効用）を性格で重み付けして選ぶ方式。反応の遅れや狙いのブレは乱数（シード固定）。

### 2.7 必殺技（遠距離弾）
- 必殺ポイントを威力と効果に振る。効果ごとに必要ポイントが異なり、全効果は付けられない。
- 効果: 不可視 / 巨大化 / 多段ヒット / 拘束 / 豆粒化（高威力） / 高速 / ゆらゆら追尾 / 打ち上げ→落下。矛盾した組み合わせも可。
- 合成: 弾の基本値 → 掛け算系の効果 → 足し算系の効果 → 軌道の追加 → 特殊挙動（拘束など）の順で固定適用。同じ構成なら毎回同じ珍挙動になる。
- ゲーム上の上限は設けない。ただし**エンジン保護**（弾数上限・数値の暴走/NaN 検査・寿命）は落ちないために入れる。
- 効果ごとのコストは JSON で外出しし、プレイ実績を見て調整する。
- キャラ作成画面に試し撃ち場。

## 3. バトル
- 1対1、有界アリーナ、障害物なし。制限時間・決着条件は試作で決める。
- 戦闘計算と描画を分離。30Hz 固定ステップ、乱数シード固定で同じ入力なら同じ結果（リプレイ・観戦に使う）。
- 空間は平面＋高さ（打ち上げ弾用）。
- スマホ操作: 左に仮想スティック（画面基準の方向）、右に攻撃・防御・必殺ボタン。通常攻撃は近くの相手へ自動で向く。
- PC操作: キーボード＋マウス。
- 通常攻撃: 手を振る近接攻撃。手の長さ→リーチの対応は試作で決める。

## 4. 観戦モード
- 保存キャラ2体を選ぶ（またはランダム）→ 両者 AI で対戦を再生。
- 決定的計算なので、シードを共有すれば同じ試合を再現できる。

## 5. ランキング・マッチング
- キャラごとのレーティング（イロレーティング）。戦績はブラウザからの申告をそのまま採用。
- ランダムマッチ / ランキング上位から相手を選んで挑戦。
- 観戦の結果はランキングに反映しない（案）。

## 6. 通報（バッド評価）
- 対戦後・観戦後・キャラ詳細でバッド評価。
- バッドが一定数を超えたキャラを管理者の一覧に出し、管理者が非表示・削除。
- 緊急停止スイッチ: 他人のキャラ配信を止めて CPU キャラだけで遊べる状態にする。

## 7. アカウント
- 登録不要の匿名ゲスト（端末ごとのトークン）。
- iPhone Safari は7日間使わないと保存データが消えることがあるため、引き継ぎコードを発行。

## 8. 技術スタック（完全無料構成）
- フロント: TypeScript + Three.js + Vite。
- ホスティング: Cloudflare Pages（無料）。
- サーバー: Cloudflare Workers（無料枠）+ D1（無料枠のデータベース）。
- 画像は保存しない: キャラはストロークと凍結済みパーツ情報だけ保存し、ブラウザ側で描画を再生成する（画像保存・配信の費用がかからない）。
- 無料枠を超えたら、課金せずにサービスを一時停止する（その時点で止まる設定）。
- 利用規約・プライバシーポリシー・削除依頼窓口を用意する。

## 12. 絵の形による性能（形の性能・SHAPE_VERSION 1）
係数は `src/shape.ts` の `SHAPE`。長さは絵の長辺で割るので、描いた大きさに依らない。倍率は 0.6〜1.6 になだらかに収める。

| 形 | 強み | 弱み |
|:--|:--|:--|
| 足が長い | 歩くのが速い（大股） | 軽く吹き飛ばされやすい |
| 足が短い | 吹き飛ばされにくい | 遅い（ちょこちょこ） |
| 足が多い | 安定 | 3本目以降は少しずつ遅い |
| 足なし | 転がる: 最高速が速い（丸いほど）、勢いを付けた体当たりは最大1.5倍 | 慣性で止まりにくい、転がり中の防御は4割カット |
| 手が長い | 届く | 威力ダウン（振りかぶりの遅さは弱めた）。スタミナ増は無し ※ユーザー決定 2026-10-09 |
| 手が多い | 1回の攻撃で複数回当たる（√実効本数） | 1発が軽い・疲れる・押し返せない。必殺ゲージは攻撃1回につき1 |
| 手なし | 体当たり（重いほど強い・吹き飛ばしが強い） | 反動で与ダメージの2割を受ける（体力1で止まり自滅しない）※ユーザー決定 |
| 塗りが多い | 重い＝吹き飛ばされにくい | 遅い |
| 横に広い | ― | 当たり判定が大きい |

## 13. 必殺技の型: 近接（遠距離と選択式・予算20は共通）
- 撃てる条件は遠距離と同じ（通常攻撃5回）。構え→攻撃→戻り。構え中に殴られると潰れる。戻りは無防備。
- 届く距離 = 体の縁 ＋ 描いた手（無ければ体）の長さ × 倍率。基本威力16。状態異常は防御で防げる（つかみは防御無視）。
- 状態異常は時間を足さず長い方で上書き。

| 効果 | 内容 | コスト |
|:--|:--|:--|
| 巨大な手 | 手足3倍・届く距離2.2倍・構えが遅い | 6 |
| ゴム伸びパンチ | 一番長い手が伸びる・届く距離3.5倍・狭い・戻りが遅い | 4 |
| 竜巻スピン | 1.5秒回り全方向に最大6回。終わると自分が目を回す（操作がうねる） | 8 |
| 突進すり抜け | 前へ5走り抜ける（竜巻中は回転の向きへ＝変な方向へ飛ぶ） | 5 |
| 地面たたき | 跳んで叩き、輪の衝撃波（内側は安全） | 5 |

|:--|:--|:--|
